# Simple Interest Calculator

A Bash script to calculate simple interest based on user input.

## Description
This project contains a simple Bash script that calculates simple interest using the formula:
**Simple Interest = (Principal × Rate × Time) / 100**
**Simple Interest = (Principal × Rate × Time) / 100 sure**

## Usage
1. Clone the repository
2. Make the script executable: `chmod +x simple-interest.sh`
3. Run the script: `./simple-interest.sh`
4. Enter the required values when prompted

## Requirements
- Bash shell
- bc (basic calculator) - usually pre-installed on Linux/Mac

## Example

Enter Principal amount: 1000
Enter Rate of Interest (in %): 5
Enter Time period (in years): 2
Simple Interest: 100.00
Total Amount: 1100.00
